Yardtech-1 is a retro-inspired game engine written in C++ that is currently in its early stages of development. The project is published and developed under the MIT license. In its later stages, the code aims to read and render the BSP v30 system. While the game code for Goblet of Blood, the engine's first game, is not yet clearly separated from the engine code, it will be organized as a dynamic library named gbgame.dll in the future.
